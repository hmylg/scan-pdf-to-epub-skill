# QA 验收清单

每个勾选项都应在 QA 报告中附证据。没有路径、命令输出、截图或阅读器记录的勾选，不算证据。

## 输入和范围

- [ ] 记录原 PDF 路径、大小、页数和 SHA-256。
- [ ] 原 PDF 未被覆盖或重新保存。
- [ ] 已确认书名、作者、语言、字形策略、输出目录和目标阅读器。
- [ ] 已记录个人使用、授权和公开发布范围。
- [ ] 已记录操作系统和架构；需要 Apple Vision 时已检查可用性。
- [ ] 已记录 OCR 引擎、包、模型、选项和离线状态。
- [ ] 所选 OCR 路线明确：路线 A 使用 PaddleOCR 3.7+ 和 PP-OCRv6 medium det/rec；路线 B 将用户已提供且获准的 AI Studio `.md`/`.json` 对应到源页。
- [ ] `work/ocr/engine-preflight.json` 已记录缓存、下载、运行状态和失败原因。
- [ ] 路线 A 只运行一个 PaddleOCR pipeline 实例、复用缓存，subagent 未另起 OCR runner；路线 B 未为重复结果而安装或运行本地 PaddleOCR。
- [ ] 重新处理前已审计既有文件和 QA。

## 页面清点和图片

- [ ] 每个 PDF 页都有稳定 manifest 条目。
- [ ] 已区分单页和双页。
- [ ] 每个双页都有按本页确定的 gutter/裁切记录。
- [ ] 已登记封面、书脊、书名页、版权页、空白页、插图和后记。
- [ ] 每个原页都对应正文、特殊页/插图或确认空白页。
- [ ] 记录每张图片的来源页、裁切、哈希、EPUB 位置和替代文字。
- [ ] 图片处理可回退，没有补画或生成原图中不存在的内容。

## OCR 和精校

- [ ] 所有本地运行的引擎使用同一图片和裁切；路线 B 记录外部输入映射及未知预处理，不声称具有同图像可比性。
- [ ] 每个完成的引擎/页面组合都保存原始 JSON。
- [ ] 候选文本保留 page ID 和阅读顺序。
- [ ] 如使用 AI Studio，已记录 `.md`/`.json` 外部来源；若直接采用，已明确记录其为主候选，未将其冒充本地 OCR。
- [ ] 路线 B 未要求或询问第二个 OCR 引擎；只有用户明确要求额外对照时才例外。
- [ ] 路线 A 的差异路由或路线 B 的视觉风险抽检覆盖漏行、重行、顺序错误和标点/数字风险。
- [ ] 风险页均回看高清扫描。
- [ ] 已重点复核专名、标题、混合文字、引号、省略号、破折号、数字、网址和 ISBN。
- [ ] 已复核跨页段落、对白、书脊边缘和插图邻页。
- [ ] 最终文本与原始候选分开冻结。
- [ ] 可复现修复和一次性人工决定可区分。
- [ ] 未进行翻译、润色、语义补写或基于置信度的自动选字。

## CER 证据

- [ ] 基准页覆盖普通、困难、混排和插图邻接版式。
- [ ] 金标准文本如存在，则由独立人员只看扫描制作。
- [ ] CER 使用替换数加删除数加插入数除以参考字符数。
- [ ] 已写明归一化规则，没有用归一化掩盖错字或标点错误。
- [ ] 无效、不完整或页码对应错误的盲录已标记无效。
- [ ] 条件不满足时，报告明确写“未取得正式 CER 认证”。

## EPUB 结构

- [ ] 每章/语义区段有可维护 XHTML 和可见标题。
- [ ] OPF spine、EPUB 3 导航和兼容 NCX 一致。
- [ ] 封面元数据和封面资源一致。
- [ ] 必要的纸书页锚点存在，且没有意外公开 page-list。
- [ ] 正文可搜索、可调字号。
- [ ] 图片引用有效并有合适替代文字。
- [ ] 内部链接和资源路径都能解析。

## 机器和阅读器检查

- [ ] ZIP 完整性通过。
- [ ] mimetype 是首项且未压缩。
- [ ] container 指向正确 OPF。
- [ ] 自定义结构检查通过。
- [ ] 原样记录 EPUBCheck 版本和结果。
- [ ] 已搜索章节独特短语、漏章和重复段落。
- [ ] 在范围内完成 Apple Books smoke test。
- [ ] 在范围内完成微信读书 smoke test。
- [ ] 测试的是重新导入的最终 EPUB，不是旧缓存。
- [ ] 已检查不同宽度、字号、行距和浅色/深色背景。

## 交付

- [ ] EPUB、源目录、工具、manifest 和 QA 报告齐全。
- [ ] 记录源 PDF 和最终 EPUB 哈希。
- [ ] 原始 OCR、候选、最终页和修复日志仍可追溯。
- [ ] 公开仓库没有私人或未获授权的书籍内容。
