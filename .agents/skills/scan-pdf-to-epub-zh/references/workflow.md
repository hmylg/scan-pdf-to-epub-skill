# 工作流程参考

处理新书或恢复中断项目时阅读本文件。

## 各阶段产物

| 阶段 | 必须产物 | 应暂停的情况 |
| --- | --- | --- |
| 前置检查 | 来源记录、哈希、页数、平台和用户决定 | 元数据或隐私范围不清 |
| 页面清点 | 缩略图、单页/双页分类、特殊页清单 | 页面无法安全分类 |
| Manifest | 稳定 page ID、裁切框、状态和来源 | 某个原页没有去向 |
| OCR 基准 | 同图像、同裁切的本地引擎原始 JSON | 引擎无法本地运行或结果不可比 |
| 全文 OCR | 候选结果缓存和可恢复日志 | 批处理会覆盖原始输出 |
| 精校 | 冻结的 final-pages、视觉决定和修复日志 | 只凭置信度或通顺度选字 |
| EPUB 构建 | 可生成源目录、EPUB 和构建日志 | 正文或图片位置仍在变化 |
| QA | 机器检查、阅读器 smoke test 和未解决风险 | 把 ZIP 通过误认为阅读器兼容 |

## 前置检查记录

机器可读的来源记录至少包括：

- 原 PDF 绝对路径、文件大小、页数和 SHA-256。
- 文件格式、文字层、书签、旋转和页面尺寸。
- 书名、作者、语言、字形保留规则和繁简策略。
- 可重排或固定版式目标，以及目标阅读器。
- 输出目录，以及个人使用、已获授权或公开发布范围。
- 操作系统、架构、本地 OCR/模型版本和网络/离线状态。

不要把私人路径或云服务凭证写入公开报告。

## Manifest 设计

物理原页使用稳定 page ID；双页拆分时为左右裁片使用独立 ID，并明确保留它们和原页的关系。

建议状态顺序：

1. discovered
2. classified
3. extracted
4. ocr-complete
5. candidate-compared
6. proofed
7. illustration-ready 或 confirmed-blank
8. epub-placed
9. qa-checked

不要从 discovered 直接跳到 proofed。若某状态不适用，记录原因，不要删除页面。

## 双页拆分

每个双页：

1. 查看高清整页。
2. 根据暗带、空白、页边或文字边界定位实际书脊。
3. 记录裁切框和旋转。
4. 同时保存未修改的物理页和 OCR 用裁片。
5. 检查裁片边缘是否缺字、带入阴影或改变阅读顺序。

只有裁切框或图片哈希改变时才重新 OCR；保留旧候选供比较。

## OCR 和候选路由

同一裁片交给每个本地引擎，记录引擎名称、包/模型版本、选项、图片哈希、运行日期和原始结果路径。引擎升级必须在 manifest 中可见。

基准集应覆盖版式风险，而不只是容易识别的正文。除非有独立有效金标准，否则基准集只能用于路由和回归，不能称为正式准确率认证。

候选比较后：

- 把漏行或多行页面列入队列。
- 把左右页反转、列顺序错误页面列入队列。
- 把人名、标点、数字、网址或混排文本有分歧的页面列入队列。
- 在全书搜索同一种错误模式。
- 任何修复前都打开扫描核对。

## 精校记录

每项重要决定保留 page ID、扫描区域或视觉说明、旧候选、最终文本、校对者、日期和理由。确定性替换只有在扫描证据和受影响页清单明确时才可使用。

不要无条件统一引号、破折号、省略号、全半角或异体字。跨页对白很容易制造假阳性。

## 构建和恢复

从冻结逐页文本和 manifest 构建。生成的 XHTML 可以丢弃重建；逐页文本、图片元数据、配置和修复日志必须可恢复。

中断后：

1. 读取 manifest 和构建日志。
2. 对比图片哈希、引擎和版本元数据。
3. 保留有效原始输出。
4. 只重跑缺失或无效状态。
5. 任一源页变化后重新做差异和 QA。

生成的 EPUB 不是事实源；源目录必须足以重新构建。

## 隐私和公开发布

私人扫描、完整 OCR、封面图、版权页和书籍专属转录，不应进入公开仓库，除非用户拥有权利并明确批准。公开 fixture 应使用合成、公共领域或允许再分发的样本。
